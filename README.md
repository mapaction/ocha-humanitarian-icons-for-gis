# OCHA Humanitarian Icons
<img src="https://www.unocha.org/sites/unocha/files/icons_banner_2_1.jpg" alt="Humanitarian Icons" width="300px" align="right" > These icons were created by [The United Nations Office for the Coordination of Humanitarian affairs (OCHA)](https://www.unocha.org). [MapAction](https://mapaction.org) has supported in the creation of the various GIS ready formats for ESRI (ArcGIS Pro) and QGIS.

Version 3.0 has 377 icons in 19 categories. Each icon is a character in the font Humanitarian-Icons, and a ready-made symbol (15 pt, black, with a white halo 0.5 pt wide and 50 per cent opaque) in the ArcGIS Pro and QGIS style files.

## Version history
* [Version 1.0 - 2012](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/tree/humanitarian-icons-v1)
* Version 2.0 - 2019 - A refresh and update of the version 1 icons.
* [Version 2.1 - 2020](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/tree/humanitarian-icons-v2) - The addition of COVID-19 related icons.
* Version 2.2 - 2021 - Minor updates.
* Version 2.3 - 2024 - Nutrition icon updated.
* Version 3.0 - 2026 - 18 icons added (377 in total), icons in alphabetical order, new halo (0.5 pt, 50 per cent white) on the symbols, new font and style files. The ArcMap 10.6 style, the EOT and WOFF fonts and the SVG based QGIS file are no longer provided. Character codes are unchanged, so existing maps keep working.

## Formats
### Font
* .ttf

### Graphics
* .svg (black, 48 by 48 square)
* .png (black, 500 by 500 pixels, transparent background)

### GIS friendly
#### ESRI
* .stylx for use in ArcGIS Pro
#### QGIS
* .xml using the .ttf font file for use in QGIS 3.10 and above
