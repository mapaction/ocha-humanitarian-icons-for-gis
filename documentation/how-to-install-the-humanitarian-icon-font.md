# How to install the humanitarian icon font
<img src="https://github.com/mapaction/ocha-humanitarian-icons-for-gis/blob/humanitarian-icons-v3/documentation/images/fonts-view.jpg" alt="Fonts" width="95%" align="centre" >

Install the font before you open ArcGIS Pro or QGIS. The icons will not draw until it is installed.

## Windows
1. Download the font - [Humanitarian-Icons.ttf](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/raw/humanitarian-icons-v3/humanitarian-icons-v3-font/Humanitarian-Icons.ttf).
2. Right-click the file and choose Install for all users (or double-click it and choose Install).
3. Close and reopen any GIS program that was open.

## Mac
Double-click the file and choose Install Font.

## If an earlier version is installed
Remove it first (Windows: Settings, Personalisation, Fonts, select Humanitarian-Icons, Uninstall), close all GIS programs, then install this version. The character codes have not changed, so existing maps keep working.

## Using the font in other programs
Each icon is a character from U+E900 upwards. The characters are listed in the [icon lookup table](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/blob/humanitarian-icons-v3/documentation/icon-lookup-table.md).
