# How to install the humanitarian icons in ArcGIS Pro
<img src="https://github.com/mapaction/ocha-humanitarian-icons-for-gis/blob/humanitarian-icons-v3/documentation/images/arcgis-pro-logo.jpg" alt="ArcGIS Pro Logo" width="150" align="right" >The following instructions will take you through installing the icons to use in ArcGIS Pro. The style file was saved with ArcGIS Pro 3.7.

## You will need
* The humanitarian icons font
* The .stylx file

## Installation
### Download
1. Download the .ttf font - [Humanitarian-Icons.ttf](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/raw/humanitarian-icons-v3/humanitarian-icons-v3-font/Humanitarian-Icons.ttf).
2. Download the .stylx file - [ArcGIS Pro .stylx file](https://github.com/mapaction/ocha-humanitarian-icons-for-gis/raw/humanitarian-icons-v3/humanitarian-icons-v3-arcgis-pro/humanitarian-icons-arcgis-pro.stylx).

### Install the font
3. Right-click the font and choose Install for all users.
4. Restart ArcGIS Pro if it was open.

### Install the .stylx file
5. Open ArcGIS Pro and open the project you are working on.
6. On the Insert tab, in the Styles group, click Add, then Add Style.
7. Locate the .stylx file and click OK.
8. The style is now ready to use. It is listed in the Catalog pane under Styles.

<img src="https://github.com/mapaction/ocha-humanitarian-icons-for-gis/blob/humanitarian-icons-v3/documentation/images/arcgis-pro-styles.jpg" alt="ArcGIS Pro Style Manager" width="95%" align="centre" >

## The symbols
Each symbol is 15 pt and black, with a halo of 0.5 pt in white at 50 per cent opacity. The halo is a setting of the symbol and is kept when you change the colour or size. Symbols are grouped by category.
